# 手機與電腦瀏覽器操作 SDD

## 目標與範圍

同一頁面支援手機觸控與桌面滑鼠鍵盤，讓使用者完成 SVG／DXF 匯入、指定刀路、調整順序、設定 CAM 參數、預覽與生成 `.nc`。CAM 幾何與 G-code 演算法不因輸入裝置而改變。

## 規格

| 編號 | 行為 | 驗收條件 |
| --- | --- | --- |
| M1 | 窄螢幕單欄版面 | 320、360、390px 無文件水平捲動；主要按鈕至少 44px 高 |
| M2 | 2D 跨裝置操作 | 輕點選刀路；單指移動、雙指縮放；桌面滾輪縮放與拖曳框選保留 |
| M3 | 精準觸控 | 手機線段有透明 24px 命中區；手勢結束不誤觸選取 |
| M4 | 視圖復位 | 「適合畫面」還原縮放與平移 |
| M5 | 排序 | 清單上下鍵與桌面拖曳皆可排序；最短路徑設定的影響明確提示 |
| M6 | 3D 容錯 | WebGL 初始化失敗時，2D 編輯與 G-code 流程仍可操作 |
| M7 | 下載 | 點擊生成後保留 Blob URL 一段時間，供瀏覽器完成下載 |

## LOOP 紀錄

1. **檢查**：原介面已有 1024px 單欄斷點；2D 僅用滑鼠滾輪與滑鼠事件，排序僅靠拖曳。
2. **實作**：新增 Pointer Events 手勢模組、窄螢幕尺寸規則、手機命中區、視圖復位與排序按鈕；3D 初始化失敗時停用 3D 分頁；延後釋放下載 URL。
3. **驗證**：`npm test` 通過 49/49；Chrome 裝置尺寸模擬下 320／360／390／768px 無水平溢出，360px 匯入兩條 SVG 路徑、觸控選取、雙指縮放、還原視圖與按鍵排序成功。未在實體 iOS／Android 裝置驗證下載與 3D 效能。
