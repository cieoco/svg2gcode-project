# 加工安全與匯入狀態 SDD

## 目標

修正非貫穿切深、SVG 隱藏幾何、匯入失敗後的舊設計，以及極大陣列造成的瀏覽器卡頓。生成 G-code 前必須明確拒絕不能安全解釋的輸入。

## 驗收條件

| 編號 | 條件 |
| --- | --- |
| S1 | 非貫穿深度必須有限、> 0、< 材料厚度；無效值不得退回預設切深，直接呼叫 CAM API 亦須拒絕 |
| S2 | SVG 的 `display:none` 及 `visibility:hidden` 幾何不匯入；`visibility:visible` 子節點可覆寫繼承的隱藏，子節點不能覆寫祖先 `display:none` |
| S3 | 新檔案載入開始時舊路徑與 3D 預覽清空，載入期間禁止生成；錯誤、讀取失敗與不支援的檔案不得恢復舊刀路；過期的非同步載入結果不得覆寫新檔 |
| S4 | 陣列最多 400 組且展開後最多 2000 條路徑；超限在預覽或生成前顯示錯誤，不開始建立大量副本；沒有設計圖的純清掃不受無關陣列設定影響 |

## LOOP 驗證

1. **重現**：材料厚度 7 mm 時，非貫穿深度 0、−1、20、NaN 原先分別輸出錯誤切深或穿透；隱藏 SVG 路徑原先仍匯入；匯入錯誤後舊路徑仍可生成。
2. **修正**：輸入、CAM API 雙層驗證切深；解析 SVG 時處理顯示屬性與繼承；載入新檔即清除舊設計並以序號隔離非同步結果；陣列在預覽與複製前驗證上限。
3. **回歸**：55/55 自動測試通過。Chrome 實際頁面操作確認：有效 SVG 匯入、錯誤 SVG 清空並停用生成、超限陣列顯示錯誤、非貫穿過深阻擋、合法深度可生成。

SVG 仍非完整渲染器；顯示屬性、inline style 及 SVG 內基本 class／id CSS 顯示規則會影響匯入。外部樣式表與不支援的 CSS 規則會明確拒絕匯入，避免隱藏圖形誤入刀路。
